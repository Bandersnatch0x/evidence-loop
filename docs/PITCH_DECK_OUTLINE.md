# 初赛 PPT / 路演提纲

建议 8-10 页，总时长 5 分钟。

## 1. 封面
- EvidenceLoop · 循证实训 Agent
- Boundless Agents · AI+教育
- 提交 → 证据 → 诊断 → 再验证

## 2. 问题
- 自动批改只给对错
- AI 讲评容易幻觉、越权改分
- 教师看不到可行动的证据队列

## 3. 方案
- 用可验证证据驱动评分
- 模型只解释，不改分
- 教师只获干预建议，不自动写成绩

## 4. 目标用户与价值
- 学员：可解释反馈 + 下一轮任务
- 教师：班级学情 + 关注队列
- 课程团队：可复用 Agent 模板

## 5. 任务闭环
- 提交代码
- 受限运行
- 量规评分
- 知识诊断
- 修复再验证

## 6. Demo
- 缺陷提交：80 分 / 7/8 证据
- 应用修复：100 分 / +20
- 班级视图同步

## 7. 技术架构
- EvaluationAgent 五步
- Python 运行器 + 量规 + 知识库
- 可选 LLM 反馈，失败回退本地策略

## 8. 安全与合规
- 匿名样例
- 模型不改分
- 子进程仅 Demo 级
- 生产前换容器沙箱

## 9. 开放复用
- Apache-2.0
- 任务/量规/诊断模板可复制
- README + 架构 + ADR 完整

## 10. 路线图
- 复赛：容器沙箱 + 数据库 + 更多任务
- 决赛：现场答辩与视频
- 产品化：LMS 对接与人工确认写分

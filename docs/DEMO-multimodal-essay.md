# 演示脚本：作文作业 · 段落指点

**场景**：预设作文段落 → 学生问「第二段哪里可以改进？」→ 系统语音反馈 + 高亮第二段 DOM。

**前置**：
- `MULTIMODAL_ENABLED=true`
- 当前 Phase 1 以代码 + KaTeX 数学为主；作文可用 **DOM 锚点示意** 演示同一协议（`[HIGHLIGHT:selector=...]`）。
- 若现场无独立作文作业页：在工作台任意带 `data-evidence-id` 的段落节点上演示指点即可，话术说明「作文同协议」。

## 预设初始数据

| 项 | 值 |
|----|-----|
| 示意正文 | 第二段：论点展开不足，缺少例证与过渡句 |
| 学生提问 | 「第二段哪里可以改进？」 |
| 目标 selector 示例 | `[data-evidence-id="essay-para-2"]` 或现有证据节点 |
| 合规约束 | 转写走 PII 检测；审计不落原文；24h TTL |

### 预设作文（可粘贴到备注 / 投影讲稿）

> **第一段** 开头点题……  
> **第二段** 作者只写了「我认为很重要」，没有事实或数据支撑，段末也没有回扣中心。  
> **第三段** 结尾仓促……

## 期望交互步骤

1. 投影或打开带段落锚点的页面；说明作文与代码共用 **同一 directive 协议**。
2. 学生按住说话：「第二段哪里可以改进？」
3. 系统回复讲解（结构 / 例证 / 过渡）并高亮第二段。
4. 强调：**不自动改分、不写入正式成绩**；教师保留认定权。
5. 切换教师 → 班级学情 → 「语音辅导使用次数」仅显示次数。

## 预期输出

- 语音讲解包含可操作的改进建议（例证、过渡、主题句）。
- Overlay 高亮第二段节点后淡出。
- `POST /api/multimodal/ask` → `X-Modality-Mode: voice`。
- 审计 metadata：`transcriptChars` 等计数，**无**「第二段哪里可以改进？」字符串。
- 学生角色访问 `/api/cohort/multimodal-usage` → **403**。

## 故障应急

| 现象 | 处理 |
|------|------|
| 无作文专用页 | 用数学/代码页讲「同协议」；selector 换成现有 `data-evidence-id` |
| 高亮整页闪烁 | selector 过宽；收紧到段落级节点 |
| 转写含姓名学号 | STT finalize / PII 门返回 422；演示「命中即拒存」 |
| 评审追问笔迹 | 明确 Phase 2 + ADR-0007 前置，Phase 1 不做 canvas |

## 叙事收束

> 多学科共用一套「讲解 + 指点」协议；学科差异只在 DOM 锚点与 SPEAK/DISPLAY，不在评分闭环。

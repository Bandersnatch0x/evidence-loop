## 开场 30 秒（板书铁律）

**EvidenceLoop = 循证实训 Agent**  
学生作答 → Runner 出可复现证据 → **只证据打分**；LLM 只辅导，**永不改分**。

> 证据打分 · LLM 不改分 · 练习≠正式掌握 · 终裁不折叠 · 提示不是分 · PII 不出境

---

## 主路径时间盒（10–12 min）

| 时 | 段 | 操作要点 | 一句口播 |
|----|----|----------|----------|
| 0:00 | 铁律 | 板书六句 | 分数只来自证据 |
| 0:30 | 学生 | 我的练习 → **老师提示**收件箱 | 消息不是分 |
| 1:30 | 学生 | 今日该练 → **练习态** → 求助 | 辅导不改分 |
| 2:30 | 学生 | 提交 → **错题本重练**（仍练习态） | 重练不伪装测评 |
| 3:30 | 学生 | （可选）**成套计时交卷** | 仪式壳，计分仍在单题 Attempt |
| 4:30 | 教师 | `tu-demo` → **布置**测评态 | 占位 Attempt，未交不算掌握 |
| 5:30 | 教师 | **发提示**多选/全班 → 切回学生收 | T14 只碰消息 |
| 6:30 | 教师 | **主观题终裁**（有则演示） | 写 annotation，不折叠 score |
| 8:00 | 学情 | 班级中位分 | 待终裁不进正式中位 |
| 8:30 | 可选 | 多模态 / 弱网 | 只读不改分；flag 可关 |
| 9:30+ | Q&A | 见下表 | — |

**只剩 5 分钟时砍成四步：**  
铁律 → 练习态求助不改分 → 教师终裁不折叠 → 提示不是分。

## 专家问答（脱口版）

| # | 问 | 答（≤2 句） |
|---|----|-------------|
| 1 | 分数是模型编的？ | 否。只消费 Runner `Evidence`；LLM 标 `llm_inference`，与打分路径物理隔离。 |
| 2 | 练习 vs 测评？ | 练习可辅导、喂 FSRS、**不进**正式掌握；测评关辅导、**进** MasteryProfile。 |
| 3 | 终裁改客观分？ | 否。写 `teacherAnnotation`+签名，与 `score` 并列；无批量给分。 |
| 4 | 提示会加减分？ | 否。站内消息，不写 score / evidence / MasteryProfile。 |
| 5 | 成套另有计分？ | 否。计时交卷是 UI 仪式；分仍在各题 Attempt。 |
| 6 | 合规？ | 容器隔离、HMAC 审计链、PII 扫描、**学生 PII 永不出境**；Demo 假多租户要诚实。 |
| 7 | 多模态污染分？ | 否。语音只读高亮讲解；flag 关即回退。 |
| 8 | 和 AI 家教差？ | 不是对话即分；编排可解释、可审计、可复现。 |
| 9 | 没做啥？ | Excel/PDF 导出 fog（CSV 有）；家长端/短信出界；批量 Attempt API 未做。 |

## 故障 10 秒处理

| 现象 | 立刻做 |
|------|--------|
| 端口挂 | `PORT=5280` 或 `node output/restart-dev-server.cjs` |
| 角色错 | 再切演示角色 + 硬刷新 |
| 无提示 | 教师对 `tu-demo` 发一条 → 学生刷新 |
| 无成套 | 教师手选 ≥2 题**测评态**再布置 |
| 终裁空 | 改讲数据模型：annotation 不折叠 score |
| 多模态灭 | 查 `MULTIMODAL_ENABLED`；走 fallback 脚本 |

## 验收信号（心里有数）

- 求助前后 **score 不变**  
- 提示投递后学生收件箱出现，**成绩区无变化**  
- 终裁后 annotation 可见，**客观分未被覆写**  
- 学情待终裁计数 / 中位分门禁说得通

## 赛道定位

Boundless Agents（无界应用）聚焦真实行业场景中的 AI Agent 落地。鼓励围绕个人终端、汽车出行、金融服务、教育、工业制造等场景，构建具备任务理解、流程编排、工具调用、知识增强、多轮交互和结果交付能力的智能体应用。

不鼓励：
- 泛聊天机器人
- 单点问答工具
- 简单内容生成器

希望：
- 面向真实用户与真实业务流程
- 至少完成一个可演示、可验证的任务闭环
- 形成可持续使用的应用雏形

## AI+教育重点验证

- 个性化学习
- 作业辅导
- 学情诊断
- 教师备课
- 学习陪伴

## 核心作品要求

1. 至少一个可演示、可验证的任务闭环
2. 清楚说明目标用户、场景痛点、交互流程、技术路线、数据来源、合规边界和后续迭代计划
3. 说明模型、Agent 架构、工具接口、知识库、数据处理与部署方式
4. 对数据授权、隐私保护、风险提示和行业边界做明确说明
5. 鼓励开放可复用的模板、组件、示例数据或技术文档

## 评审关注

1. 行业场景价值
2. Agent 能力与任务闭环
3. 产品体验与 Demo 完成度
4. 技术实现深度与工程可复现性
5. 安全、合规与开放复用价值

## 指南补充

- 可使用商业 API 或云服务，但需在材料中说明
- 需说明关键技术依赖和开源边界
- 团队需确保知识产权、数据合规和安全风险可控
- 代码仓库建议提供 README 和部署说明

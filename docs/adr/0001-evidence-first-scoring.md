# ADR 0001：证据优先评分

## 状态

已采纳

## 背景

教育场景中，如果让 LLM 直接给分，会出现不可复现、难审计、易幻觉的问题，也不符合正式成绩流程。

## 决策

1. 分数只由测试证据与静态检查经量规计算。
2. LLM 仅用于组织受证据约束的反馈文案。
3. 教师视图只提供干预建议，不自动写正式成绩。
4. 运行失败时返回 blocked/failed，不给安慰分。

## 后果

### 正面
- 评分可解释、可复现
- 模型能力退化为“讲解层”，风险可控
- 与赛事对 Agent 任务闭环和合规边界的要求对齐

### 代价
- 需要先建设任务、量规与知识库
- 不能靠模型“聪明判断”掩盖测试不足

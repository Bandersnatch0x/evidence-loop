# PRD：EvidenceLoop

## 产品目标

在编程实训中，把“自动批改”升级为“证据驱动的诊断与再训练 Agent”，并保持评分可解释、可复现、可审计。

## 用户故事

### 学习者
1. 作为学员，我提交代码后希望看到证据清单，而不是一句“再想想”。
2. 作为学员，我希望知道失败证据对应哪个知识点。
3. 作为学员，我希望拿到下一轮最短修复任务，并能再次验证是否修好。

### 教师
1. 作为教师，我希望看到班级完成率、中位分和需要关注的人。
2. 作为教师，我希望干预建议可审查，而不是系统自动写正式成绩。

## 功能范围（当前 Demo）

### 已实现
- 学习工作台：任务、量规、编辑器、版本切换、评估结果
- 评估 Agent 五步闭环
- 证据面板、知识诊断、干预任务、Agent trace
- 班级学情视图
- 项目透明度页
- 本地规则反馈；可选 OpenAI-compatible 反馈
- 响应式布局（桌面/平板/手机）

### 明确不做（当前阶段）
- 真实学籍/LMS 对接
- 多租户权限系统
- 生产级容器沙箱
- 自动成绩写入
- 多语言编程题全量覆盖

## 成功标准

1. 同一提交多次评估分数稳定
2. 缺陷→修复路径可在 3 分钟内演示
3. `npm run check` 通过
4. 材料完整说明合规边界与限制

# 循证环 · EvidenceRing · 决赛现场固化 SOP

> 决赛 2026-09-22/23 现场路演 + 答辩的固化检查表与降级决策树。本文收紧自 [DEMO-preflight.md](./DEMO-preflight.md)，针对决赛现场（评委在场、时间紧、环境不可控）做了加严与决策树化。
> 配套：口播稿 [DEMO-oral-10min.md](./DEMO-oral-10min.md) · 卡点 [DEMO-cue-card.md](./DEMO-cue-card.md) · 问答库 [DEMO-expert-qa.md](./DEMO-expert-qa.md) · 弱网 [DEMO-weaknetwork-drill.md](./DEMO-weaknetwork-drill.md)。
> 身份常量：学生 `learner-demo` · 教师 `teacher-demo` · 单元 `tu-demo` · 端口 `5280`（备用 `18473`）。
> 铁律编号：①证据打分 ②LLM 不改分 ③练习≠正式掌握 ④终裁不折叠 ⑤提示不是分 ⑥PII 不出境。

## 一、时间轴检查表

### T-30 min · 环境 / 端口 / 数据 / 角色

> 目标：服务起来、数据在、角色能切。不做新功能，不改代码。

**环境**

- [ ] `cd D:/code_space/evidence-loop`（或决赛机 clone 后的 `evidence-ring` 目录）
- [ ] `$env:PORT='5280'; npm run dev`（4173/5173 可能 EACCES，直接用 5280）
- [ ] 浏览器开 `http://127.0.0.1:5280`，硬刷新一次（Ctrl+Shift+R）
- [ ] 确认现场网络：若评审现场无公网，提前设 `MULTIMODAL_ENABLED=false` 或 `STT_PROVIDER=webspeech`（见弱网清单）
- [ ] （可选但强烈建议）`node scripts/e2e-demo-loops.mjs http://127.0.0.1:5280` -> 目标 **16/16**；不绿先别上场

**数据 / 角色**

- [ ] 侧栏「演示角色切换」能切 **学生 / 教师**
- [ ] 学生侧 `learner-demo`：「我的练习」可见，老师提示收件箱（可空）、今日该练、错题本在
- [ ] 教师侧 `teacher-demo`：单元 `tu-demo` 可选，布置 / 发提示 / 批改 tab 能打开
- [ ] 若 e2e 没跑，手动确认：求助能出字、提交有分数面、错题本有重练入口

**硬件 / 投影**

- [ ] 主屏投产品 UI，分辨率适配（防 UI 错位）
- [ ] 副屏 / 纸质：[DEMO-cue-card.md](./DEMO-cue-card.md) 贴屏或打印
- [ ] 麦克风 / 音频：若演示多模态语音，确认 Chrome 麦克风权限已允许
- [ ] 逐字稿 [DEMO-oral-10min.md](./DEMO-oral-10min.md) 仅备用，尽量看 UI 讲

---

### T-20 min · 数据路径摸一遍（不念稿，手过一遍）

> 目标：肌肉记忆，上场时手不抖。每步确认验收信号。

- [ ] 学生：我的练习 -> 老师提示（可空）-> 今日该练进**练习态**
- [ ] 练习态：求助能出字 / 失败则改走直接提交（**求助前后 score 不变**）
- [ ] 提交一题，有分数面（证据可见）
- [ ] 错题本有重练入口，重练徽章仍是**练习态**
- [ ] （可选）成套场次有倒计时 / 交卷按钮；没有就记口播降级句
- [ ] 教师：`tu-demo` -> 布置 1 题**测评态**成功（创建占位 Attempt）
- [ ] 教师：发提示 1 条 -> 切回学生刷新收件箱**可见**，**成绩区无变化**
- [ ] 教师：批改 tab / 学情页能打开（终裁有则点，无则只讲模型）
- [ ] 学情：中位分 / `pendingAdjudication` 待终裁计数显示正常

---

### T-10 min · 嘴（口播肌肉记忆）

> 目标：铁律不看稿能背，收束能脱口，红队底线不破。

- [ ] **铁律六句**不看稿顺出：证据打分 · LLM 不改分 · 练习不等于正式掌握 · 终裁不折叠进客观分 · 提示不是分 · 学生隐私数据不出境
- [ ] **开场两句**能脱口：「别家把算力花在让 AI 老师更像人，我们把工程花在让分数更像证据。」+ 一句话定义
- [ ] **收束三句**能脱口：信任在证据 / 智能在辅导 / 权威在教师终裁
- [ ] **多 Agent 收束句**：多 Agent 是分工，不是分数的多个来源
- [ ] **红队底线**默念：不装生产多租户；不说 LLM 改分；不承诺 Excel/PDF、家长端、短信、批量交卷 API；主动披露 fog 项

---

### T-5 min · 最终自检（决赛加严）

> 目标：上场前最后一道关，任何一项不绿立刻启动降级决策树。

- [ ] 服务进程还在，浏览器标签没被关，UI 没白屏
- [ ] 当前角色停在**学生 · 我的练习**（开场位）
- [ ] 端口 5280 可达；若挂了立刻换 18473 或 `node output/restart-dev-server.cjs`（见决策树 D1）
- [ ] 收件箱状态确认：有未读就用现成的；空就在心里准备好「教师侧发一条再回来」
- [ ] 多模态 flag 状态确认：现场有网且要演示语音就 `MULTIMODAL_ENABLED=true`；否则 `false` 关掉保评分闭环
- [ ] 计时器 / 提词在手（10 分钟时间盒：0:00 铁律 / 0:40 学生 / 5:10 教师 / 7:20 终裁 / 8:30 边界 / 9:20 收束）
- [ ] 备用口播路径在心里：若只剩 5 分钟，砍成四步（铁律 -> 求助不改分 -> 终裁不折叠 -> 提示不是分）
- [ ] 深呼吸 3 次

---

### T-1 min · 心态 / 开场句

> 目标：稳住，开场第一句定调。

- [ ] 站定，看评委，不先碰鼠标
- [ ] 默念开场第一句：「各位老师好。我演示的是循证环，EvidenceRing--循证实训 Agent。」
- [ ] 默念差异化定调句：「别家把算力花在让 AI 老师更像人，我们把工程花在让分数更像证据。」
- [ ] 提醒自己：演示要诚实，边界要主动说，被问穿不慌（问答库兜底）
- [ ] 把手放到鼠标上，深呼吸，开始

## 二、必演示铁律路径清单

> 这些动作**必须在现场做到**，每条对应一条铁律。若某条因故障无法演示，立刻走第三节决策树降级，**不得跳过铁律不提**--口播也要把铁律念出来。

| # | 必演示动作 | 验收信号 | 对应铁律 | 降级口播（做不到时） |
|---|-----------|---------|---------|---------------------|
| 1 | 提交一题，展示 Runner -> Evidence -> 分数 | 分数面有证据来源，非"模型觉得" | ① | 「Runner 产证据、Rubric 归约，我指证据区说明。」 |
| 2 | 练习态点求助 + 点「朗读讲解」，手指分数区 | **求助前后 score 不变**，AI 在说话分数不动 | ② | 「主评分不依赖大模型；我直接提交展示证据分。」 |
| 3 | 进练习态看徽章 + 错题本重练看徽章 | 徽章始终「练习态」，不伪装测评 | ③ | 「练习态喂 FSRS 不进正式掌握，测评态才进。」 |
| 4 | 教师终裁写批注 + 学情看中位分/待终裁 | annotation 可见，**客观分未被覆写**；待终裁不进正式中位 | ④ | 「数据模型上 annotation 与 score 并列；待终裁不进正式中位。」 |
| 5 | 教师发提示 -> 切学生收件箱 | 新提示可见，**成绩区无变化** | ⑤ | 「我先在教师侧发一条再回来。」或讲 T14 只碰消息 |
| 6 | 边界段口播（容器/审计/PII/诚实多租户） | 主动披露 fog 项，不装生产级 | ⑥ | 口播即可，无需点击；可指 `X-Security-Warning` 头 |

**铁律演示顺序建议**（与口播稿对齐）：①开场铁律 -> ②③学生段 -> ④教师终裁段 -> ⑤发提示段 -> ⑥边界段。即使砍成 5 分钟版，②④⑤ 三条铁律的动作不能省。

## 三、故障降级决策树

> 每个情况给「判断 -> 15 秒切换动作 -> 衔接口播句 -> 恢复后回切」。原则：**不慌、不冷场、不暴露故障为产品缺陷**，15 秒内切到备用路径继续讲。

### D1 · 端口挂了 / 服务起不来

```
判断：浏览器白屏 / 连接被拒 / EACCES
  ├─ 15 秒动作：
  │   1. 口播不停：「我换备用端口拉起服务。」
  │   2. 终端：$env:PORT='18473'; npm run dev
  │      或：node output/restart-dev-server.cjs
  │   3. 浏览器改开 http://127.0.0.1:18473，硬刷新
  ├─ 衔接口播句：「现场端口冲突，我用备用端口，几秒钟就好。」
  ├─ 恢复后回切：回到当前时码对应操作继续
  └─ 全挂兜底（服务起不来）：开场铁律六句 + 架构口播，指 ADR-0001 / 仓库 README，转 Q&A
```

### D2 · 收件箱空（老师提示没数据）

```
判断：学生侧「老师提示」收件箱空，无未读
  ├─ 15 秒动作：
  │   1. 不停留，口播：「我先在教师侧发一条再回来。」
  │   2. 切教师 -> tu-demo -> 发提示（正文「注意边界条件」）-> 多选 learner-demo 或留空全班 -> 发送
  │   3. 切回学生 -> 刷新收件箱 -> 指新提示
  ├─ 衔接口播句：「提示是站内消息，我现场发一条演示闭环。」
  ├─ 恢复后回切：继续「消息不是分」铁律⑤讲解
  └─ 注意：发提示后必须指给评委看「成绩区无变化」
```

### D3 · 求助慢 / 求助失败

```
判断：点求助后 llm-thinking 卡住 / 报错 / 无文本
  ├─ 15 秒动作：
  │   1. 不等，口播：「主评分不依赖大模型；我直接提交展示证据分。」
  │   2. 直接提交一题 -> 走 Runner -> Evidence -> 分数
  │   3. 手指证据区，讲「分数来自这些证据，不是模型」
  ├─ 衔接口播句：「辅导走语音/LLM 通道，打分走证据通道，两条路物理隔离--所以辅导挂了不影响分。」
  ├─ 恢复后回切：若 LLM 恢复可补演示朗读讲解；否则继续错题本/成套段
  └─ 红线：绝不为了等 LLM 卡住冷场超 15 秒
```

### D4 · LLM 完全失败 / 无 LLM_API_KEY

```
判断：辅导全程无响应 / 离线环境
  ├─ 15 秒动作：
  │   1. 跳过求助演示，口播：「未配 LLM_API_KEY 时完全离线可运行，主评分闭环不依赖模型。」
  │   2. 直接提交 -> 展示证据分（铁律①②照样验证）
  │   3. 多模态段若也依赖 LLM，切 mock 或关 flag
  ├─ 衔接口播句：「模型是可摘掉的能力增强，不是评分的硬依赖--这本身就是铁律②的工程体现。」
  ├─ 恢复后回切：继续练习态/错题本/教师段
  └─ 优势点：把"无 LLM 也能跑"转成卖点，反而强化铁律②
```

### D5 · 无待终裁（主观题终裁入口空）

```
判断：教师批改 tab 无待裁主观题
  ├─ 15 秒动作：
  │   1. 口播：「数据模型上 annotation 与 score 并列；有待裁时走同一入口。」
  │   2. 指向已有终裁行 / 学情页的 pendingAdjudication 计数
  │   3. 或指向数据模型文档 / 代码路径 SubjectiveGradingService
  ├─ 衔接口播句：「终裁写 teacherAnnotation 带签名，与客观分并列不折叠--这是架构保证，不止是 UI 演示。」
  ├─ 恢复后回切：继续学情中位分 / 门禁讲解
  └─ 备选：现场用预置主观题快速造一条待裁（若 T-30 已备好则直接用）
```

### D6 · 无成套场次（计时交卷没数据）

```
判断：学生练习场次里没有「成套 + 测评态」
  ├─ 15 秒动作：
  │   1. 口播：「成套是仪式壳，我用单题 Attempt 说明计分权威。」
  │   2. 跳过成套段，直接切教师布置段
  │   3. 或现场造：教师手选 ≥2 题测评态布置 -> 学生场次出现成套（若时间允许）
  ├─ 衔接口播句：「成套计时交卷是 UI 仪式，没有第二套计分 API--Attempt 才是成绩聚合根。」
  ├─ 恢复后回切：跳到 5:10 教师布置段
  └─ 红线：绝不暗示成套另有计分逻辑
```

### D7 · 多模态不亮 / 语音失败（现场无网或无密钥）

```
判断：VoiceCompanion 不出现 / STT 503 / 麦克风无权限
  ├─ 15 秒动作：
  │   1. 判断是否要演示语音：若非必须，口播「语音只读不改分，flag 可关」直接跳过
  │   2. 若必须演示：切 STT_PROVIDER=webspeech 重启，或用预录转写
  │   3. 完全无麦：放 30s 预录短视频（docs/screenshots/demo-videos/）
  ├─ 衔接口播句：「语音只读证据、不改分；flag 关即回退，评分闭环零回归。」
  ├─ 恢复后回切：多模态是可选项，跳过不影响铁律演示
  └─ 详见 [DEMO-weaknetwork-drill.md](./DEMO-weaknetwork-drill.md) 逐段降级
```

### D8 · 角色错乱 / UI 状态不对

```
判断：侧栏角色不对 / 数据串角色 / 页面残留
  ├─ 15 秒动作：
  │   1. 再切一次「演示角色切换」到目标角色
  │   2. 硬刷新（Ctrl+Shift+R）
  │   3. 确认 x-demo-role 请求头（dev-only MockSession）
  ├─ 衔接口播句：「演示用假会话切换角色，我刷新一下。」
  ├─ 恢复后回切：继续当前段
  └─ 注意：刷新期间口播不停，讲架构或铁律填空
```

## 四、演示后不要做（红队底线）

- [ ] 不要当场承诺 Excel/PDF 导出、家长端、短信推送
- [ ] 不要承诺成套批量提交 API（当前是 UI 仪式壳）
- [ ] 不要说「LLM 帮忙改分 / 一键全班给分」
- [ ] 不要改代码「加个 LLM 改分」
- [ ] 不要把本地 Python 子进程说成生产沙箱
- [ ] 不要宣称已上线生产级多租户 / 密钥托管
- [ ] 不要把多 Agent 说成新增了 Agent 框架 / 多进程编排（是现有模块对外命名）

## 五、演示后答辩衔接

- 路演结束念收束三句：「信任在证据 / 智能在辅导 / 权威在教师终裁」+「请各位老师提问」
- 答辩优先翻 [DEMO-expert-qa.md](./DEMO-expert-qa.md)（5 维度 30+ 预判问题 + 铁律快答卡）
- 铁律被质疑时先念快答卡钉死立场，再请评委看支撑路径
- 拿不准的问题诚实说边界，不编造未实现功能（ROADMAP `[ ]` 项按"有意后置"回答）
